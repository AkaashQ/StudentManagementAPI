# Student Management API

## Project Description
This project is a Student Management API developed using Python Flask, SQLite, and Streamlit.

It allows users to view, add, update, and delete student records.

## Technologies Used
- Python
- Flask
- SQLite
- Streamlit
- Requests
- Pandas

## API Features
- GET: View all students
- POST: Add a new student
- PUT: Update student information
- DELETE: Delete a student

## How to Run
1. Install the required packages:
   `pip install -r requirements.txt`
2. Start the Flask API:
   `python app.py`
3. Open another terminal and start the interface:
   `streamlit run frontend.py`
